# URL → Markdown 변환 후 LLM으로 넘기기

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 프롬프트를 붙여 ChatGPT·Claude로 바로 넘길 수 있게 합니다.

프로토타입(구현 시 반드시 읽음): [prototype.html](prototype.html). 화면 구성, 요소 순서, 상태별 모양(로딩·오류·본문 없음·결과·알림), 390/768 폭 배치를 정합니다. 가짜 데이터와 주소 분기 로직은 시연용이며 제품 동작이 아닙니다.

관련 결정 계약(구현 시 반드시 읽음):

- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md): 입력·버튼·프롬프트 선택·상태 표현을 shadcn 구성과 semantic token으로 만드는 기준, loading·empty·error 상태를 정상 화면과 함께 설계하는 기준
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md): 새로 들이는 의존성(defuddle, DOM 구현, Markdown 렌더러 등)의 버전 표기 기준

## 사용자가 얻는 결과

- 기사나 문서의 URL 하나로 광고·내비게이션이 빠진 본문 Markdown을 얻습니다.
- 그 결과를 클릭 한 번으로 복사하거나 `.md` 파일로 받습니다.
- 원하는 지시(요약·번역·쉬운 설명 또는 직접 쓴 문장)를 붙여 ChatGPT나 Claude 새 대화로 바로 넘깁니다.

## 범위

1. **입력**: URL 입력란 하나와 변환 실행, 지우기 버튼
2. **변환**: 서비스가 해당 페이지를 가져와 defuddle로 본문을 Markdown으로 추출
3. **결과 확인**: 제목·저자 헤더와 렌더링된 Markdown
4. **내보내기**: 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기
5. **프롬프트**: 프리셋 3종과 1회용 직접 입력
6. **다크모드 토글**

## 수용 기준

### 입력

- URL 입력란에 주소를 붙여넣고 변환을 실행할 수 있다. Enter 키로도 실행된다.
- `http://` 또는 `https://`로 시작하지 않거나 URL 형식이 아니면 변환을 요청하지 않고 입력란 근처에 오류를 보여 준다.
- 지우기 버튼을 누르면 입력란, 변환 결과, 오류 메시지, 프롬프트 선택, 직접 입력 내용이 모두 처음 상태로 돌아간다.
- 입력란이 비어 있으면 변환 실행 버튼은 비활성이다.

### 변환

- 본문 추출은 defuddle 라이브러리로 한다(사용자 요구, 대체 불가).
- 변환이 진행되는 동안 로딩 상태가 보이고, 변환 실행 버튼을 다시 누를 수 없다.
- 페이지를 가져오지 못하면(네트워크 오류, 4xx/5xx 응답) 원인을 짐작할 수 있는 오류 메시지를 보여 주고 입력한 URL은 그대로 남는다.
- 추출된 본문이 비어 있으면 "본문을 찾지 못했습니다"류의 빈 상태를 보여 준다.
- 다음 페이지에서 제목과 비어 있지 않은 본문이 나온다: `https://stephango.com/file-over-app`, `https://ko.wikipedia.org/wiki/마크다운`.

### 결과 확인

- 결과 상단 헤더에 페이지 제목이 보인다.
- 저자가 있으면 제목 아래에 보이고, 비어 있으면 저자 줄 자체가 나타나지 않는다(빈 라벨이나 "알 수 없음"을 표시하지 않음).
- 본문은 Markdown 원문이 아니라 렌더링된 형태(제목, 목록, 링크, 코드 블록, 표 등)로 보인다.
- 원본 페이지의 스크립트나 임의 HTML이 결과 화면에서 실행되지 않는다.

### 내보내기

- **복사하기**를 누르면 내보내기 문서(아래 가정 참고)가 클립보드에 들어가고, 성공했다는 피드백이 보인다.
- **.md 다운로드**를 누르면 같은 내보내기 문서가 `.md` 파일로 저장된다. 파일 이름은 페이지 제목에서 파일명에 쓸 수 없는 문자를 뺀 값이다.
- **ChatGPT로 열기**, **Claude로 열기**는 각각 새 탭에서 해당 서비스의 새 대화를 연다.
  - 프롬프트를 고르지 않았으면 내보내기 문서만 넘긴다.
  - 프롬프트를 골랐으면 프롬프트 문장, 빈 줄, 내보내기 문서 순으로 이어 붙여 넘긴다.
  - 넘길 전체 텍스트를 주소에 담았을 때 기준 길이 이하이면 주소에 담아 입력창이 채워진 상태로 연다.
  - 기준 길이를 넘으면 넘길 전체 텍스트를 클립보드에 복사한 뒤 빈 새 대화를 열고, "본문을 클립보드에 복사했습니다. 입력창에 붙여넣으세요"라는 안내를 이 서비스 화면에 보여 준다.
- 변환 결과가 없을 때는 내보내기 버튼 4개가 모두 비활성이다.

### 프롬프트

- 프리셋은 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘" 3개이고, 프리셋 옆에 "직접 입력" 선택지가 있다.
- 한 번에 하나만 고를 수 있고, 고른 것을 다시 누르면 선택이 풀려 프롬프트 없음 상태가 된다. 처음 상태는 프롬프트 없음이다.
- "직접 입력"을 고르면 텍스트 입력란이 나타나고, 다른 선택으로 바꾸면 사라진다.
- 직접 입력한 문장은 저장되지 않는다. 새로고침하거나 지우기를 누르면 사라진다.
- "직접 입력"을 골랐는데 입력란이 비어 있으면 프롬프트 없음과 똑같이 동작한다.
- 프롬프트는 ChatGPT·Claude로 열기에만 붙고, 복사하기와 `.md` 다운로드 결과에는 들어가지 않는다.

### 다크모드

- 화면의 토글로 라이트·다크를 바꿀 수 있고, 모든 상태(로딩, 오류, 결과, 안내)가 두 모드에서 모두 읽힌다.

## 확정된 제약과 이유

- **defuddle 사용**: 사용자 요구입니다. 스크래치 환경(Node 26, `defuddle@0.19.6`, `defuddle/node` + `linkedom`)에서 위 수용 기준의 두 페이지와 Next.js 블로그, Hacker News를 추출해 동작을 확인했습니다. `defuddle/node`는 페이지를 직접 가져오지 않고 이미 만든 `Document`를 받으므로, 페이지를 가져오는 일과 DOM 구현은 서비스가 맡아야 합니다. 브라우저에서 다른 사이트를 직접 가져오는 것은 CORS 때문에 대부분 막히므로 페이지 가져오기는 서버 쪽에서 해야 합니다.
- **저자가 없는 경우가 흔함**: 검증한 4개 중 2개(Next.js 블로그, Hacker News)에서 `author`가 빈 문자열이었습니다. 그래서 저자 줄을 조건부로 표시합니다.
- **LLM 전달은 길이별 분기**(사용자 확정): 짧으면 주소에 담아 한 번에 열고, 길면 클립보드 복사 후 빈 대화를 엽니다. 위키 문서 하나가 Markdown으로 약 30KB였고, 주소에 담았을 때 입력창에 전부 채워지는지는 보장되지 않기 때문입니다. "항상 주소에 담기"는 긴 글이 잘릴 수 있어서, "항상 클립보드"는 매번 붙여넣기를 해야 해서 택하지 않았습니다.
- **프롬프트 직접 입력은 1회용**: 사용자 요구입니다.

## 가정 (구현 중 바꿔도 되는 기본값)

- **기준 길이**: 완성된 열기 주소 전체가 8,000자 이하이면 주소에 담습니다. 런타임 확인 결과에 따라 조정해도 됩니다.
- **열기 주소**: ChatGPT는 `https://chatgpt.com/?q=<텍스트>`, Claude는 `https://claude.ai/new?q=<텍스트>`를 씁니다.
- **내보내기 문서 형식**: 복사, 다운로드, LLM 전달이 모두 같은 문서를 씁니다. 첫 줄 `# 제목`, 저자가 있으면 `저자: …`, `출처: <원본 URL>`, 빈 줄, 본문 Markdown 순입니다.
- **결과 헤더**: 제목과 저자 외에 원본 URL 링크를 함께 보여 줍니다.
- **다크모드 기본값**: 처음에는 시스템 설정을 따르고, 사용자가 토글로 고른 값은 브라우저에 기억합니다(직접 입력 프롬프트와 달리 저장해도 됨).
- **화면 구성**: 한 페이지에 헤더(서비스명·다크모드 토글) → URL 입력 → 프롬프트·내보내기 카드 → 결과 순으로 쌓습니다. 세부 모양은 `prototype.html`을 따릅니다.
- **프롬프트 유지**: 고른 프롬프트는 새 URL을 변환해도 유지되고, 지우기를 누를 때만 초기화됩니다.
- **알림**: 복사·다운로드·클립보드 안내는 화면 아래 가운데에 잠깐 뜨는 토스트로 보여 줍니다.
- **변환 이력 없음**: 변환 결과는 현재 화면에만 있고 저장하지 않습니다.

## 범위 밖

- 로그인, 변환 이력, 즐겨찾기: 요청에 없습니다.
- defuddle 호스팅 API(`defuddle.md/<URL>`) 사용: 일정 요청 수를 넘으면 유료 키가 필요하고, 사용자는 라이브러리 사용을 요구했습니다.
- 로그인이 필요한 페이지, 자바스크립트로만 본문을 그리는 페이지의 추출 품질 보장: 서버가 받은 HTML만 다룹니다.
- ChatGPT·Claude 외 다른 LLM 서비스.
- 요구하지 않은 보안 하드닝, 성능 방어(AGENTS.md 검증 예산).

## 남은 위험

- **주소 채우기 동작 미검증**: `chatgpt.com/?q=`는 60,000자 주소에도 서버가 200으로 응답했지만, 입력창이 실제로 다 채워지는지는 로그인한 브라우저에서만 확인할 수 있습니다. `claude.ai/new?q=`는 브라우저가 아닌 요청을 Cloudflare가 403으로 막아 확인하지 못했습니다. 둘 중 하나가 `q`를 무시하면 짧은 글도 입력창이 빈 채로 열립니다. 구현 단계의 런타임 확인에서 실제 브라우저로 확인하고, 동작하지 않으면 해당 서비스는 항상 클립보드 경로를 쓰도록 바꿉니다.
- **한국어 글은 대부분 클립보드 경로**: 한글 한 글자는 주소에서 9자로 늘어나 8,000자 기준이 본문 약 900자에 해당합니다. 한국어 글 대부분은 붙여넣기 단계를 거칩니다.
- **추출 실패 사이트**: 봇 차단이나 자바스크립트 렌더링에 의존하는 사이트에서는 본문이 비거나 오류가 납니다. 오류·빈 상태로 처리합니다.
- **클립보드 권한**: 브라우저가 클립보드 쓰기를 거부하면 길이 초과 경로가 실패합니다. 이때는 복사 실패를 알리는 오류를 보여 줍니다.
